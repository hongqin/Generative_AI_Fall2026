# Course Project

The course project runs across all eight weeks and is worth 50% of the course grade: 40% for the written project track and 10% for the recorded final presentation. Students may work individually or in instructor-approved small teams. The topic must be related to generative AI and/or agentic AI, and should ideally align with one of the three candidate papers proposed in Week 1.

## What a project must include

- A clear problem, dataset, or research question, and a justification for using generative AI.
- A description of data and methods specific enough for a classmate to reproduce.
- Documented experiments with quantitative and qualitative results.
- A discussion of results, limitations, and responsible-use considerations.
- Supporting code with a README that explains how to reproduce the main results.
