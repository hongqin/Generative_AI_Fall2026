# Course Project Proposal (template)

Length: 500 to 1000 words (roughly 2 to 3 pages) as a PDF. Use the six sections below in this order.

## 1. Project title and team

Working title. Individual or instructor-approved team (list teammates).

## 2. Problem statement

One to two paragraphs. What is the real problem, dataset, or research question? Why does it matter? Who benefits if the project succeeds?

## 3. Background

One paragraph plus references. What is the relevant prior work, and where does this project sit relative to it? Cite 3 to 5 references (papers, textbooks, technical reports).

## 4. Approach

Which model family or families do you anticipate using (VAE, GAN, autoregressive, diffusion, transformer, world model, multimodal, agentic)? What data will you use, and how is it accessed or licensed? What evaluation metrics will you report?

## 5. Plan and timeline

Map weekly milestones onto Weeks 3 through 8. Be specific about what will be done by the end of each week. The four formal milestones (proposal now, mid-project report in Week 5, draft in Week 7, final in Week 8) anchor the timeline.

| Week | Planned work | Deliverable |
|---|---|---|
| 3 | | Implementation check-in |
| 4 | | Progress update |
| 5 | | Mid-project report |
| 6 | | Methods refinement note |
| 7 | | Draft report |
| 8 | | Final report and presentation |

## 6. Risks and mitigations

List 2 to 3 concrete risks (compute budget, data availability, evaluation difficulty, ambitious scope) and a one-sentence mitigation for each.
