# Supplementary Material

Optional notes on topics that were covered in the 16-week version of this course (CS 795, Fall 2025) but are not part of the 8-week core. They are provided for students who want to go further, and as context for project work.

- [Agentic AI](agentic-ai.md): reading pointers on LLM agents and foundation agents.
- [Conformal prediction](conformal-prediction.pdf) ([source](conformal-prediction.tex)): distribution-free uncertainty quantification.
- [Group SHAP](group-shap.pdf) ([source](group-shap.tex)): grouped Shapley-value attribution.

- Week 5: [normalizing flows](../week05-diffusion/notes/supplementary/normalizing-flows.pdf) and [energy-based models](../week05-diffusion/notes/supplementary/energy-based-models.pdf).
